# شاشات الإدارة
1. دخول موظف+OTP، اختيار نطاق فرع لمن يملك أكثر من فرع؛ لا إنشاء حساب عام.
2. لوحة يومية: جديد/متأخر/قيد المراجعة، مبيعات وعمولات، رسومات واضحة، فلترة تاريخ وفرع. حد اليوم يتبع المنطقة الزمنية التي تعتمد؛ Asia/Aden مقترح D15.
3. المحافظات والفروع: إضافة/إيقاف وترتيب، إحداثيات الفرع بالخريطة، نطاق التغطية، base/per_km مع floor_km ثابت.
4. الأقسام: ترتيب وصورة وحالة؛ الخصائص: اسم/مفتاح/قيم؛ ربط خصائص القسم required/filterable/order، إدارة قيم الماركة مثل غيرها.
5. المنتجات: اسم ووصف وصور وبلد منشأ وقسم، القيم من List/Picker، وحدات حبة/كرتون ومعامل وسعر وحالة كل وحدة. أسعار الفرع الاختيارية.
6. مخزون الفروع: حر/محجوز/فعلي، إدخال وتسوية وجرد ونقل مع سبب وسجل حركة؛ لا أرقام تعديل بلا حركة.
7. الطلبات: بحث وفلترة حالة/فرع، تنبيه بلاغ عميل سابق قبل التأكيد؛ تفاصيل البلاغ مرئية للمخول فقط.
8. مراجعة تجزئة/جملة: تعديل كل بند وإصدار revision ومتابعة قبول العميل، تغيير الفرع مع إعادة تسعير واضحة.
9. مراجعة الإيصالات: صورة خاصة ورقم ومبلغ ووسيلة ومرجع، تحذير التكرار، اعتماد/رفض مسبب، تحقق خارج التطبيق قبل الاعتماد.
10. تأكيد/رفض، إسناد موصل، إعادة إسناد مسموحة قبل الطريق، مراقبة التأخر وبلاغات تعذر التسليم.
11. الموصلون: حساب/نطاق/تفعيل/نسبة عمولة من التوصيل، سجل التعديلات، مستحقات اليوم/غير المسدد/تسويات.
12. المحافظ والتحويل: اسم الوسيلة والمستفيد والرقم والتعليمات وترتيبها ونطاقها؛ لا تكامل API وهمي.
13. عروض وبنرات، رسائل وبث مستهدف ومجدول، معاينة المحتوى والثيم.
14. الشكاوى والتقييمات وبلاغات العملاء؛ حالات مفتوح/قيد المعالجة/محلول مع رد إداري.
15. موظفون وأدوار وصلاحيات ونطاق فروع، سجل تدقيق، تقرير شهري PDF عربي قابل للمشاركة.
16. صيانة العميل، إعدادات الإصدار لكل تطبيق ومنصة، روابط الخصوصية والدعم، إعدادات مهلة الحجز والتأخر. تأكيد إضافي داخل الواجهة للإجراءات المؤثرة، مع صلاحية خادم.
لا فيديو افتتاح، ولا تتوقف الإدارة عند صيانة العميل.

## قرارات المالك المعتمدة لمراجعة الواجهة
اختيار فرع التنفيذ يدويًا مستقل عن فرع الكتالوج. تغيير التنفيذ يرسل عرضًا وموافقة جديدين دائمًا. شاشة محاولات الإيصال تحفظ الصور والقرارات لنفس التحويل وتعليماته الأصلية، مع تنبيه الحجز المحمي وقرار صريح بعد المراجعة، دون مهلة تحرير آلية. النقد يؤكد دون إيصال ثم يعرض مبلغ التحصيل الفعلي والنقص والتوريد. افصل دفتر أموال المتجر عن العمولات، وأضف إثبات الاستثناء والعكس، دون مقاصة عمولة تلقائية أو تغيير مبلغ مؤكد.
