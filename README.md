## ابدأ هنا
ابدأ بقراءة `START_HERE_AR.md`؛ يشرح الرسائل الجاهزة لكل مرحلة، وما تراجعه قبل الانتقال، وكيف تعالج الملاحظات أو تتابع في محادثة جديدة.

1. افتح مجلد الحزمة في مستودع جديد. احفظ الملفات المرجعية ولا تستبدلها بمخرجات مولدة دون مراجعة.
2. اقرأ `MASTER_PROMPT.md` و`remember.md` و`DECISIONS.md`.
3. راجع تصميم البيانات في `backend/docs/DATABASE.md` و`backend/database/schema.sql` قبل تحويله إلى migrations.
4. أرسل للوكيل البرومبت الموجود في `backend/docs/phases/00.md` فقط مع البرومبت الرئيسي.
5. بعد مراجعة مخرجات المرحلة، أرسل ملف المرحلة التالية. لا تطلب تنفيذ كل الملفات دفعة واحدة.
