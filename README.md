# تزويد — حزمة التخطيط والأصول التنفيذية

الإصدار 1.1 — 27 أكتوبر 2026. هذه حزمة مواصفات وأصول وتعليمات متتابعة للوكيل، وليست تطبيقات مكتملة أو خادمًا جاهزًا للإنتاج.

## ابدأ هنا
ابدأ بقراءة `START_HERE_AR.md`؛ يشرح الرسائل الجاهزة لكل مرحلة، وما تراجعه قبل الانتقال، وكيف تعالج الملاحظات أو تتابع في محادثة جديدة.

1. افتح مجلد الحزمة في مستودع جديد. احفظ الملفات المرجعية ولا تستبدلها بمخرجات مولدة دون مراجعة.
2. اقرأ `MASTER_PROMPT.md` و`remember.md` و`DECISIONS.md`.
3. راجع تصميم البيانات في `backend/docs/DATABASE.md` و`backend/database/schema.sql` قبل تحويله إلى migrations.
4. أرسل للوكيل البرومبت الموجود في `backend/docs/phases/00.md` فقط مع البرومبت الرئيسي.
5. بعد مراجعة مخرجات المرحلة، أرسل ملف المرحلة التالية. لا تطلب تنفيذ كل الملفات دفعة واحدة.

## المجلدات الأربعة
| المجلد | الغرض |
|---|---|
| customer-app | تطبيق العميل، الشعار، الخط، فيديوهات الافتتاح، الأيقونة، ومرجع دمج الافتتاح |
| admin-app | تطبيق المدير وأيقونته ووصف شاشاته وصلاحياته |
| courier-app | تطبيق الموصل وأيقونته ووصف المهام والمستحقات |
| backend | الخادم المستقبلي، المواصفات، SQL المرجعي، العقود والاختبارات وخطط المراحل |

## الملفات المهمة
- `REQUIREMENTS.md`: المتطلبات المعتمدة.
- `DECISIONS.md`: تفاصيل اقترحناها لتغطية النقاط غير المحسومة؛ يجب إظهارها في مراجعة المرحلة 00.
- `START_HERE_AR.md`: دليل عمل المالك مع الوكيل خطوة بخطوة.
- `PHASES.md`: ترتيب التنفيذ ونصوص الإرسال المختصرة.
- `backend/docs/BUSINESS_RULES.md`: الطلب والمخزون والتسعير والدفع والعمولة.
- `backend/docs/SECURITY_OPERATIONS.md`: الصلاحيات والحذف والنسخ الاحتياطي والنشر.
- `backend/docs/ACCEPTANCE.md`: معايير القبول والحالات الحرجة.
- `backend/docs/SOURCES.md`: المراجع التقنية الرسمية التي تمت مراجعتها.
- `customer-app/brand-source/BRAND.md`: دليل الهوية والأصول.
- `customer-app/media/`: فيديو فاتح وآخر مظلم، 4 ثوانٍ مع صوت مدمج.
- `customer-app/integration/`: مراجع دمج الافتتاح والتحديثات وإعدادات Expo. تحتاج مواءمة مع المشروع الفعلي.
- `VALIDATION.md`: ما تم التحقق منه بالفعل وما يتبقى للتنفيذ.

## أول رسالة تنسخها للوكيل
«اقرأ README.md وSTART_HERE_AR.md وMASTER_PROMPT.md وremember.md وREQUIREMENTS.md وDECISIONS.md، ثم نفّذ المرحلة 00 فقط حسب backend/docs/phases/00.md. افحص الملفات أولًا، ولا تنشئ قاعدة الإنتاج ولا تنفذ بقية المراحل. سلّمني تقرير المراجعة والقرارات التي تحتاج الحسم وخطة الملفات قبل أن تتوقف.»

لا تتضمن الحزمة أسرارًا أو ربطًا بحساباتك. أسماء المحافظ والمحافظات والفروع الحقيقية وأرقام التحويل تُدخل من الإدارة. لا تُختلق كبيانات حقيقية.
