# شاشات الموصل
1. دخول حساب تنشئه الإدارة +OTP؛ لا تسجيل عام.
2. لوحة المهام المسندة: عدة طلبات، ترتيب وحالة وفرع، شارة جديد ومبلغ مستحق اليوم.
3. تفاصيل: رقم الطلب، اسم العميل والهاتف والعنوان ودبوس دقيق، البنود والكميات والوحدة والفرع، زر اتصال/واتساب/ملاحة خارجية.
4. تنفيذ: «بدء التوصيل» ثم «تم التسليم» مع تأكيد لمس قصير قبل التنفيذ. لا رفض ولا قبول للإسناد. retry آمن عند انقطاع الشبكة. pending network لا يعرض التسليم مؤكدًا قبل الخادم.
5. بلاغ على العميل/تعذر التسليم: طلب وسبب وتفاصيل وصورة اختيارية، يظهر للمدير، لا يضع العميل في حظر آلي.
6. المستحقات: عمولات اليوم من رسوم التوصيل قبل خصم التوصيل فقط، سجل الأيام والطلبات والنسب المثبتة، مسدد/غير مسدد، تفاصيل التسويات. لا أرباح من قيمة البضائع.
7. مركز إشعارات بصوت مهام، حساب وثيم ودعم وسياسات وخروج. Cache محدود للطلبات المسندة يمسح عند الخروج/انتهاء صلاحية الإسناد.
لا تتبع حي أو صلاحية موقع خلفي؛ لا فيديو افتتاح؛ لا تعطيل بسبب صيانة العميل؛ لا عرض كل إيصالات العملاء المالية.

## النقد والعمولة وفق قرار المالك
إظهار نوع الدفع والمبلغ النقدي المطلوب دون إيصالات تحويل العميل. تسجيل «استلمت نقدًا» بالمبلغ الحقيقي والمرجع إجراء مستقل؛ عند النقص/التعذر سجل استثناءً للإدارة. زر تم التسليم لا ينشئ مبلغًا افتراضيًا. صفحة النقد تعرض محصل/مورد/متبقٍ للمتجر، مستقلة عن مستحقات العمولة، دون طرح العمولة تلقائيًا. أساس العمولة والنسبة المثبتان ظاهرين مع خصم العميل الذي يتحمله المتجر.
