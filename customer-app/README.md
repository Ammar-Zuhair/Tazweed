```bash

# Expo Go الموافق SDK57 عبر نفق الإنترنت، منفذ العميل8091:
```

للتشغيل المستمر من الجذر استخدم `bash backend/scripts/start-expo-tunnels.sh`؛ [دليل Expo Go والخدمات](../backend/docs/EXPO_GO.md). معاينة نفس التطبيق في المتصفح: https://tazweed--8081.dev.remote-ammar.duckdns.org ، وقد تطلب دخول remote.futrx.

اختر محافظة ثم جرّب الأقسام والفلاتر والحبة/الكرتون والجملة. الدخول التجريبي يقبل رقم الاختبار770000000 وكلمة اختبار من8أحرف، ثم الرمز000000؛ لا تستخدم بيانات حساسة. حد3محاولات وإعادة إرسال بعد30ثانية وصلاحية دقيقتين إعدادات معاينة فقط.

بعد إرسال الطلب يظهر انتظار اختيار المدير. من تفاصيله افتح «محاكاة أحداث الإدارة لهذا الطلب» لإصدار تسعيرة أو تغيير الفرع أو محاكاة مراجعة الإيصال والتأكيد والتسليم. هذه أدوات اختبار محلية وليست واجهة الإدارة للمرحلة03. مختبر المعاينة يتيح الشبكة/الفراغ/الأخطاء/الصيانة/التحديث، وإعادة بيانات الجلسة.

المظهر والمحافظة فقط يحفظان على الجهاز. الحساب والعناوين والطلبات والصور تبقى في ذاكرة الجلسة؛ إعادة تحميل التطبيق تعيد بيانات الاختبار. منتقي الصور يختار ملفًا محليًا دون رفع، ويمكن استخدام صورة اختبار. «موقعي» والخريطة محاكاة صريحة دون GPS أو خرائط حقيقية. تعليمات التحويل غير قابلة للدفع، والدعم ينسخ رسالة اختبار لأن رقم واتساب لم يزود.
