# إعادة اختبار المخطط
من هذا المجلد: npm install ثم npm test.
تستخدم الاختبارات PGlite (محرك PostgreSQL/WASM في الذاكرة)، ولا تتصل بقاعدة إنتاج ولا تحتاج حسابًا خارجيًا. أثبتت هذه الحزمة إنشاء56جدولًا ورفض22حالة مخالفة للقيود.
ليست اختبارات تطبيق أو API أو تزامن خادم. تستعمل بيانات وهمية داخل ذاكرة الاختبار فقط. المرجع الأساسي schema.sql. لا تنقل المستخدمين التجريبيين إلى الإنتاج.
