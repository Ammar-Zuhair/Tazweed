# الخرائط والمسارات في07

الخادم وحده يقرأ إعدادات `ROUTING_*`. اختيار `osrm` يفعّل محول OSRM Route v1. خريطة العرض مستقلة عن خدمة حساب الطريق: يعرض MapLibre GL JS6.16.0 المثبت في backend بيانات OpenFreeMap داخل WebView13.16.1، أو إطار في معاينة الويب. لا مفتاح لخريطة OpenFreeMap العامة، ولا يخرج مفتاح الطريق إلى التطبيق.

هذا بديل يحافظ على طلب المالك Expo Go57؛ مكتبة MapLibre Native تحتاج development build. WebView وLocation57.0.22 من قائمة Expo57 الفعلية. نجاح التصدير وWebGL في المتصفح لا يثبت تشغيل هاتف أو دعم كل جهاز.

## الإعدادات في backend/.env

| الاسم | المطلوب |
|---|---|
| `ROUTING_PROVIDER` | يبقى `UNCONFIGURED` حتى التجهيز، ثم `osrm`. |
| `ROUTING_BASE_URL` | جذر OSRM مملوك أو متعاقد عليه، HTTPS بلا query أو credentials. يدعم path prefix. |
| `ROUTING_API_KEY` | اختياري: Bearer token إذا كانت بوابة OSRM محمية. OSRM الخام لا يصدر مفاتيح. |
| `ROUTING_PROFILE` | `driving` افتراضيًا؛ يجب أن يطابق graph السيارة المجهز. |
| `ROUTING_TIMEOUT_MS` | مهلة فنية500–10000، افتراضي5000؛ تشمل الطلب وقراءة الجسم. |
| `ROUTING_MAX_SNAP_M` | أقصى ابتعاد فني للدبوس عن الطريق،1–1000، افتراضي200. ليس نطاق توصيل تجاريًا. |

لا تستخدم خادم demo عامًا للتسعير الإنتاجي، ولا تضع السر في URL. يسمح HTTP على loopback في غير الإنتاج فقط. إذا اختير مزود بعقد مختلف يحتاج محولًا؛ مفتاح شركة أخرى لا يجعلها متوافقة مع OSRM تلقائيًا.

الرد محدود512KiB وهندسته حتى10000نقطة. يرفض المحول redirects والحقول المعيبة والمهلة وNoRoute/NoSegment وابتعاد snap. لا تسجل إحداثيات العميل أو عنوان طلب المزود في logs. يحتفظ snapshot بالمسافة الخام؛ `distance_m=floor(raw_m)` يطابق مخطط SQL، و`floor_km` وحده يحدد الفاتورة. يفحص حد الطريق المسافة الخام قبل حذف الكسر. موقع الوجهة يبقى في البيانات الخاصة؛ لا يُضمّن في snapshot مالي دائم.

## الاستضافة والتكلفة

لم يُشتر أو يُنشر خادم Routing إنتاجي. OSRM مفتوح المصدر، لكنه يحتاج CPU وRAM وSSD وتحديث بيانات OSM ومراقبة وTLS. لا رقم تكلفة ثابت قبل قياس graph اليمن وحمل الطلبات وتواتر التحديث. يمكن استضافته على جهاز خاص أو استخدام مزود متعاقد بعقد OSRM؛ عرض الخريطة لا يوفر مسافة تسعير.

خطوات يراجعها المشغل قبل التشغيل: تنزيل بيانات Yemen بصيغة `.osm.pbf` من مصدر موثق مع تاريخ؛ `osrm-extract -p car.lua` ثم `osrm-partition` و`osrm-customize` ثم `osrm-routed --algorithm mld` على loopback. يثبت إصدار أو بصمة image عند التنفيذ، وتقاس موارد المعالجة وحجم graph، ثم تضاف بوابة TLS وBearer وحدود طلبات. لا تعرض OSRM الخام للعامة ولا تبدأ تجهيزًا كبيرًا دون ميزانية موارد معتمدة. حدّث graph ذريًا وراقب زمن الرد وNoRoute وتاريخ البيانات.

التغطية التجارية من PostgreSQL: فرع الكتالوج الصريح، إحداثياته، تفعيل التوصيل، نطاق التغطية، التعرفة وحد الطريق وإصدارها. المسافة الهندسية فلتر خارج النطاق فقط، ولا تدخل حساب الرسوم. معاينة07 تعرض تقديرًا من فرع الكتالوج؛08 ستعيد الحساب من فرع التنفيذ الذي يختاره المدير وتثبته بالطلب.07 لا تنشئ طلبًا أو عرضًا أو حجزًا.

## فحص المواقع الفعلية المؤجل

لا مواقع متجر أو محافظات أو فروع حقيقية في قاعدة المراجعة، ولا Routing مهيأ. بعد ملء المالك للإعدادات وطلبه فحص الخدمات معًا: إدخال الفرعين الحقيقيين وتعرفة كل منهما، واختبار عناوين معروفة داخل وحافة وخارج التغطية، ودقة الدبوس وGPS ورفض الإذن، والطريق الفعلي واتجاهاته وإغلاقاته، و2.8كم وأقل من1كم، وحد الطريق وانقطاع المزود وتغيير المحافظة. هندسة الخط المستقيم في fixture الاختبار ليست طريقًا حقيقيًا أو بيانات متجر.
