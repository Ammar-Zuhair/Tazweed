# تشغيل ومراجعة أساس التطبيقات — المرحلة01

هذه ثلاثة تطبيقات Expo/React Native مستقلة داخل المجلدات الحالية، وهيكل Express فقط. نسخة الويب أداة لمعاينة **التطبيق نفسه**، وليست منتجًا خامسًا. لا خدمات طلبات أو مصادقة أو قاعدة بيانات فعلية في01. بيانات المعاينة معلّمة ولا تنفذ تعاملات.

## المتطلبات والتثبيت

Node22 بإصدار22.13 أو أحدث ضمن22، وnpm10. الإصدارات المباشرة مثبتة دون `^` أو `~`، ولكل مشروع `package-lock.json` مستقل. شغّل من الجذر:

```bash
bash setup.sh
# مع متصفح اختبارات الواجهة ومكتباته النظامية:
bash setup.sh --browser
```

الفحوص في كل مجلد تطبيق:

```bash
npm run typecheck
npm test
npx --no-install expo install --check
npm run export:web
npm run export:native
```

الأمر الأخير يصدر حزم JavaScript وأصول Android وiOS فقط، ولا يبني APK/IPA. لا تستبدل اختبار جهاز أصلي بمعاينة المتصفح. البناء المحلي يتطلب Android SDK وJDK متوافقين، أو macOS/Xcode لـiOS. `npm run android`/`npm run ios` ينشئان مشروعًا أصليًا من config plugins ثم يبنيانه؛ المجلدان المولدان مستبعدان من Git.

## فتح التطبيقات على جهاز

من كل مجلد: `npm start` لبدء Metro بوضع development client؛ ملف `eas.json` يعرّف ملفَي development وpreview الداخليين. يلزم إعداد حساب Expo وربط المشروع الفعلي قبل أي بناء سحابي. لا يوجد EAS projectId وهمي ولا مفاتيح توقيع. معرفات `com.tazweed.preview.customer/admin/courier` وschemes الحالية للمعاينة فقط وتراجع قبل مرحلة الإصدار. `EXPO_PUBLIC_APP_ENV=production` يوقف التهيئة، لأن مستودعات البيانات في هذه المرحلة fake.

اختبار الأجهزة المطلوب: Android وiOS بالعربية ولغة جهاز أخرى للتحقق من RTL الثابت، Tajawal، الفاتح/المظلم/النظام بعد إعادة الفتح، أيقونة المشغّل وsplash، مساحات الأمان وتكبير الخط. العميل فقط: افتح الفيديو كاملًا، تخطّه، فعّل تقليل الحركة، بدّل إلى الخلفية وارجع، ثم انتقل بين الصفحات؛ لا يعاد تشغيله بعد التنقل أو العودة للمقدمة. تحقق من الصوت على جهاز فعلي مع الوضع الصامت وبدونه. المتصفح قد يمنع التشغيل الصوتي التلقائي؛ المهلة تمنع التعليق ولا نعدها إثباتًا لسماع الصوت.

## بنية التطبيق

- `app.config.ts`: الاسم والأيقونة وsplash وRTL وبيئة المعاينة، دون أسرار.
- `src/app`: Expo Router؛ جذر واحد وثلاث تبويبات تأسيسية: الرئيسية، عن تزويد، الإعدادات، وصفحة غير موجودة.
- `src/bootstrap`: تحميل Tajawal والتفضيل قبل إخفاء splash، وافتتاحية العميل وحده مرة لكل تشغيل بارد.
- `src/ui`: tokens الأصلية عبر `theme-model`، ومزوّد theme، والنص والزر والبطاقة وحالات العرض والشاشات الأساسية.
- `src/data`: واجهة foundation repository وتنفيذ fake معلّم، مع إلغاء الطلبات والتأخير والخطأ والفراغ وإعادة المحاولة. لا كتالوج أو checkout أو أرصدة حقيقية.
- `assets`: ملفات الهوية الأصلية دون تغيير. فيديو العميل في `customer-app/video`؛ `integration/IntroScreen.tsx` مستعمل مباشرة من bootstrap، و`media/rebuild_intro.py` يخرج إلى video إذا طلب توليد جديد مستقبلًا؛ لم ينفذ المولّد في01.
- `tests`: اختبارات تفضيل المظهر، وتمييز fake، والإلغاء والاسترداد ومنع بيئة الإنتاج.

ينفذ المظهر الافتراضي حسب الجهاز، والاختيار الصريح محفوظ في AsyncStorage على كل تطبيق بصورة مستقلة. يوضح فشل التخزين أن الاختيار للجلسة فقط. RTL أصلي ثابت عبر expo-localization، واتجاه التنقل عبر LocaleProvider، و`lang=ar/dir=rtl` لنسخة المعاينة. MapLibre وخدمات OTP/Routing/R2/Push وOTA ليست مفعلة؛ تضاف في مراحلها عند توفر إعداداتها. مرجع `integration/updates.ts` محفوظ وغير مستدعى، وexpo-updates في العميل معطل في التهيئة حتى10.

## هيكل الخادم

```bash
cd backend
npm run typecheck
npm test
npm run build
npm start
```

`src/app.ts` ينشئ Express مع `GET /health` فقط. الإشارة `status=ok` تعني حياة العملية؛ الاستجابة تصرح بأن قاعدة البيانات غير مهيأة والخدمات التجارية غير منفذة. المسارات الأخرى404. `src/server.ts` يضبط المنفذ والإغلاق المنظم، ويفتح افتراضيًا على loopback8084. لا يطبق SQL المرجعي ولا ينشئ migrations أو حسابات.

## المعاينات الدائمة داخل الحاوية

بعد تصدير التطبيقات استخدم `backend/scripts/serve-preview.mjs <role> <port> [exact-routed-host]`. المنافذ المقصودة8081/8082/8083 للعميل/المدير/الموصل، bind على0.0.0.0، وسماح محلي فقط ما لم يمرر اسم النطاق الخارجي الصحيح. الخادم يدعم range للفيديو، ويرفض Host غير المسموح وطرق الكتابة. شغله بخدمة systemd مستقلة لكل تطبيق؛ لا تستخدم `&` أو عملية shell مؤقتة.

اسم النطاق الخارجي يأتي من **Project slug الذي تعرضه المنصة**، لا من اسم مستودع GitHub ولا من أسرار OAuth. الصيغة `https://<project-slug>--<port>.dev.remote-ammar.duckdns.org/`. لم تتضمن بيئة هذه الجلسة slug موثقًا؛ طلب من المالك، لذلك لا نختلق رابطًا صالحًا ولا ندعي تحقق ingress قبل توفيره. حالة الخدمات والأدلة الفعلية في تقرير01.

من backend: `npm run test:preview` يختبر المعاينات المحلية الثلاث المفتوحة على المنافذ أعلاه باستخدام Chromium ويحفظ صور الثيمين ونتائج JSON في `docs/progress/phase-01-*`. يعاين ملفات الخط والاتجاه والمظهر المحفوظ وتغير النظام والتحميل والخطأ والفراغ وإعادة المحاولة وعدم طلب خدمات خارجية. ليست هذه اختبارات جهاز أصلي.
