# معايير القبول والفحوص
## الكتالوج والواجهة
- Arabic RTL حقيقي، Tajawal محلي في كل الشاشات، ترتيب الأرقام والهواتف صحيح، النص يكبر بلا قطع، contrast وحالات empty/loading/error/retry/offline.
- للزيوت فلتر لزوجة بقيم مسجلة؛ للإطارات مقاس؛ لا تعرض خاصية قسم آخر. إيقاف قيمة مستخدمة لا يكسر طلبًا سابقًا.
- منتج يباع بالحبة والكرتون: الطلب 2×12 +3 يستهلك27 فقط، ومع رصيد26 يرفض الخادم مهما عدل العميل payload.
- تغيير المحافظة يعيد تسعير السلة ويعرض ما لم يعد متاحًا، دون حذف صامت أو عرض مخزون فرع خاطئ.

## تنافس وأموال
- طلبان متزامنان على آخر مخزون: واحد يحجز وينجح والآخر يتلقى409، لا reserved>on_hand ولا رصيد سالب.
- قبول quote v1 بعد إصدار v2 يرفض؛ الموافقة في جهاز قديم لا تنفذ سعرًا سابقًا.
- quote totals من الخادم؛ العبث بسعر/كمية سالبة/صفر/كسر/معامل carton/رسوم يؤدي إلى رفض.
- تأكيد دون قبول آخر quote أو دون سداد مطابق أو بحجز منتهي مرفوض. وصول إيصال لا يعني اعتماده.
- تكرار approve/confirm/deliver بسبب انقطاع الشبكة لا يكرر المال أو المخزون أو العمولة.
- تسوية موصلين أو موظفين لنفس earnings بالتزامن لا تصرفها مرتين. العمولة من التوصيل النهائي وحده، مع اختبار خصم التوصيل والصفر.
- الإيصال المكرر والتعديل بعد إيصال والدفع الزائد أو الناقص لها معالجة واضحة، لا تأكيد صامت.
- إلغاء قبل التأكيد يحرر الحجز؛ بعده يفشل حتى عبر API مباشر. صلاحية المشرف لا تسمح بحذف حركة مالية.

## نطاق الصلاحيات
- عميل لا يقرأ طلب غيره ولا إيصال غيره. الموصل لا يقرأ طلب غير مسند له أو مخزون أو سجل بلاغات العميل.
- موظف فرع لا يغير طلب فرع آخر، وعمليات النقل تتطلب صلاحية الفرعين.
- endpoint الإدارة لا يفتح بالتلاعب بقيمة app/header؛ staff roles لا يمكن تصعيدها من حساب محدود.
- OTP التسجيل والدخول والتغيير والحذف غير قابل لإعادة الاستخدام أو تبديل purpose؛ الرموز لا تظهر في logs. production يفشل بوضوح إذا provider غير مهيأ.

## التشغيل
- صيانة العميل تحجب إنشاء طلب جديد من API، وتبقي المدير والموصل وصفحات الخصوصية والحذف والدعم متاحة.
- تحديث OTA ينزل دون إجبار على restart؛ التالي يستخدم النسخة الجديدة، والnative المختلف لا يستقبل update غير متوافق.
- force-update بحسب app+platform+environment+build يعمل، رابط المتجر صالح قبل رفع minimum؛ لا حظر بلا إصدار متاح.
- إشعارات foreground/background/closed على أجهزة Android وiOS فعلية؛ التوصيل ليس مضمونًا في force-stop أو إذا عطّل المستخدم الإذن. مركز الإشعارات مصدر بديل.
- فيديو العميل فاتح ومظلم، 4ثوانٍ، تخطٍّ فوري بالنقر، يوقف الصوت عند التخطي والخلفية، لا يعاد عند navigation أو كل foreground، وفشل الفيديو لا يمنع فتح التطبيق. احترام تقليل الحركة وكتم الجهاز.
- تأكيد دبوس الموقع والتكلفة على مواقع الفروع الحقيقية؛ لا نشر بتعرفة تعتمد مسارات demo.
- تقارير الشهر حسب Asia/Aden وتفصل الإيراد المسدد والطلبات المسلمة والخصومات والتوصيل والعمولات، لا تعد الرفض/الإلغاء مبيعات.
- حذف الحساب من التطبيق والمتصفح فعلي، إبطال tokens، عدم الاحتفاظ بصور/مواقع بلا سبب، سياسة الخصوصية مطابقة للواقع.
- اختبار restore لنسخة DB، وفشل OTP/R2/Maps/Push دون فقد طلب أو تعليق غير منتهٍ.

## دليل كل مرحلة
فحص أنواع ولنت وبناء ما تغير، واختبارات domain للخادم وعقود وintegration مع DB فعلية. اختبارات الشاشات الأساسية عبر Maestro أو أداة مناسبة على Android/iOS. لا تعلن أن المخطط SQL أو مرجع TSX تطبيق مختبر على جهاز.
