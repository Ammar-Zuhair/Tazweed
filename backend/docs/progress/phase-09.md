# المرحلة09 — التوصيل والعمولة والجودة

نُفذت09 فقط بعد قراءة `remember.md` وتقرير08 وخطة09 ومراجعها من المستودع: MASTER_PROMPT والمتطلبات والقرارات وقرارات المالك وسجل المشكلات، وقواعد العمل وقاموس البيانات وAPI والقبول وشاشات الموصل والإدارة. لم يوجد عائق من08 يمنع التنفيذ المستقل. بقي تأجيل اختبار OTP/R2/Routing الحقيقيين بطلب المالك، ولم تبدأ10.

## النتيجة والسلوك

التطبيقات الثلاثة تتصل بالخادم؛ الموصل لم يعد شاشة انتظار. كل حالات الطلب والمبالغ والقيود والتخصيصات من PostgreSQL. لا نجاح مالي محلي أو بيانات تشغيل تجريبية بديلة. العربية وRTL وTajawal والثيمان وExpo Go57 محفوظة، دون مكتبات تحتاج development build أو تغيير قرار MapLibre07.

| الجزء | السلوك |
|---|---|
| الإسناد | عدة طلبات لموصل، وكل طلب كامل من فرعه. المدير يختار موصلًا نشطًا بفرع ونسبة صريحة؛ NULL يمنع الإسناد ولا يتحول إلى نسبة افتراضية. إعادة الإسناد قبل الطريق فقط، مع حفظ السابق وإلغاء وصول صاحبه. |
| العمولة | snapshot عند الإسناد: رسوم قبل خصم التوصيل والنسبة والخصم والمبلغ.500 قبل خصم100 عند20%=100 عمولة،400 توصيل العميل. تستحق عند التسليم مرة واحدة؛ تعديل نسبة الحساب لا يغير الإسناد، وصفر صريح لا ينشئ earning صفريًا. |
| المهمة | قائمة المسند وفرعه وحالته وعلامة جديد وعمولات اليوم UTC؛ تفاصيل التواصل والعنوان والدبوس والبنود، وفتح الاتصال/WhatsApp/الملاحة بفعل المستخدم. بدء ثم تسليم مع تأكيد قصير؛ لا قبول/رفض إسناد ولا تتبع خلفي. |
| النقد | إجراء مستقل بالمبلغ الفعلي والمرجع والوقت، دون تحصيل من التأكيد أو التسليم. النقص/التعذر/الزيادة استثناء مسبب يطابق الفرق الحالي قبل التسليم. دفتر مال المتجر مستقل عن العمولة تمامًا. |
| التصحيح والمال الخارجي | الإدارة تصحح أصل التحصيل بقيد تعويضي مسبب وإثبات خاص دون تعديل الأصل أو صافي سالب. فرق COD يحسب الفعلي والاستلام الخارجي والرد والشطب المحاسبي؛ الشطب لا يصنع نقدًا. التحصيل المتأخر بعد تسوية يفتح فرقًا جديدًا عند الحاجة، ولا يكرر العمولة. |
| الصرف والتوريد | اختيار بنود وcredits صريحة، مجموع موجب مطابق، قفل موحد للموصل وتخصيص فريد لكل مصدر. الصرف المتزامن لا يدفع البند مرتين. التوريد كامل مال المتجر دون طرح العمولة تلقائيًا. |
| العكس | صلاحية مستقلة وسبب ومرجع وإثبات خاص. عكس كامل واحد يحفظ الأصل وتخصيصاته، وينشئ credit يعاد تخصيصه مرة واحدة؛ لا حذف أو إعادة استحقاق عمولة أو مقاصة. |
| الجودة | تقييم1–5 مرة واحدة للطلب المسلم، وشكوى العميل بصورة خاصة اختيارية ورد الإدارة وإصداره. بلاغ/تعذر من الموصل الحالي أو موظف مخول؛ التنبيه السابق يظهر للمدير في طلب العميل التالي دون حظر آلي. مراجعة البلاغ لا تمس النص الأصلي. |
| الصلاحيات | ملكية/دور/عملية/فرع في الخادم، وفحص حي قبل replay وداخل المعاملة. الموصل لا يرى مهمة غيره أو إيصال تحويل أو إثبات موظف أو أرشيف العميل. الدفتر الإداري يحتاج كل فروع الموصل الحالية والتاريخية؛ حذف فرع لا يكشف ذمته القديمة. نص البلاغ ومرفقه محجوبان خارج الفرع التاريخي ولو ظهر تنبيه وجوده. |
| الاتصال | طابور08 المحمي من تأخر التخزين وتبديل الحساب ممتد للموصل؛ حفظ مفتاح ومحتوى العملية قبل الإرسال، وإعادة المحاولة نفسها بعد فقد الإقرار. لا تأكيد تسليم في الواجهة قبل رد الخادم. |

التفاصيل والمسارات وحدودها في [DELIVERY](../DELIVERY.md) و[OpenAPI09](../openapi.phase09.json). الدفاتر المالية تعرض مصادر الموصل وتسوياته/توريداته وتخصيصاتها وcredits ضمن قراءة واحدة مفوضة بدل قوائم مالية عامة. ضبط نسبة الموصل وفروعه عبر `POST /admin/couriers/{id}/configure`، بديل تنفيذي موثق لمساراتPATCH التصورية. القوائم العامة cursor1–100، والدفتر الحالي يقرأ تاريخ الموصل كاملًا؛ التقارير والتصدير في مرحلتها اللاحقة.

تُسجل الجولة النهائية في [الفحوص](phase-09-checks.json)، [القبول](phase-09-evidence/acceptance.txt)، [الواجهة](phase-09-evidence/ui-checks.json)، [الأنفاق](phase-09-tunnels.json)، و[فهرس الصور والتشغيل](phase-09-evidence/README.md). نجحت12جولة واجهة و33لقطة بالثيمين وعروض360 و390 و1024 دونpageErrors أوطلب مزود حقيقي؛ شملت فقد إقرار التسليم بعدcommit وإعادة المفتاح نفسه، والتقييم والشكوى والصورة ورد الإدارة والصرف والعكس وإعادةcredit والتوريد ونقص النقد. نجحت فحوص الأنواع وبناءbackend وصادراتالويب و6حزمHermes للمنصتين، وفحص توافقExpo57 وOpenAPI، وفحص479ملفًا/مخرجًا منها294مخرجًا بحثًا عن أسماء إعدادات الخادم وقيمه المعروفة، بلا تطابق محظور. نجح137اختبارًا للخادم والطابور والنقل و73حارسSQL؛ المجموع210 دون فشل أوskip في الجولة الكاملة النهائية. اجتازت الأنفاق الثلاثة6مانيفستات وحزم تطويرAndroid/iOS عامة و3اتصالاتWebSocket، بثبات الوحدات ودون إعادة تشغيل. نجح جامع الفحوص النهائي بتاريخ2026-11-02T17:51:14Z؛ المحاولات المتوقفة لا تعد نجاحًا. الخدمات الثماني تعمل، وPostgreSQL يحوي72جدولًا و51trigger و6migrations مطابقة، دون بيانات متجر اختبارية أو قواعد اختبار متروكة. live09 يعيد200 وready503 يعلن نقصOTP/R2/Routing صراحة معDBconnected/current/limited. معاينات8081–8083 تطابق الصادرات وترفضHost غير موثوق؛ HTTPS8081–8084 يعيد302 لبوابةremote فقط، وليس إثبات دخول مستخدم مصادقًا.

## البيئة وحدود المرحلة

**لا أسماء مفاتيح خدمات جديدة لازمة في09.** أضيف تعليق توضيحي إلى `backend/.env` فقط، مع حفظ كل القيم وصلاحية600 وgitignore. نسب الموصلين وفروعهم بيانات يديرها الموظف فيDB، لا.env. تستعمل صور الشكاوى والبلاغات والإثباتات R2 الخاص السابق، والدخول OTP السابق. لم تضف بوابة دفع أو Push أو خدمة جديدة. تبقى إعدادات OTP/R2/Routing السابقة لملئها ثم فحصها معًا بعد طلب المالك، كما في [ENVIRONMENT](../ENVIRONMENT.md).

المتبقي قبل الإطلاق: المزودات والمواقع والحسابات والعمولات الحقيقية وتجربة هاتف Android/iOS وSecureStore الفعلي والاتصال/الملاحة ورفع R2 والصلاحيات الأصلية. لا تُعد صادراتHermes أو متصفح Chromium دليل هاتف. قرار المنطقة الزمنية D15 باقٍ؛ اليوم والتواريخ موسومةUTC. إرسالPush والصوت وصندوق الإشعارات والتحديث/الدعم/التقارير/الخصوصية المؤجلة ليست ضمن09؛ outbox فقط يسجل أحداثها. **التوقف قبل10.**
