# المرحلة10 — الإشعارات والصيانة والإصدارات

نُفذ نطاق10 فقط بعد قراءة remember.md وتقرير09 وخطة10 وكل مراجعها في المستودع: قرارات المالك والمتطلبات والقرارات وسجل المشكلات وMASTER_PROMPT وRELEASES وSECURITY_OPERATIONS وAPI وACCEPTANCE وملفات updates/eas للتطبيقات. لا عائق من09 يمنع العمل المستقل. بقي تأجيل اختبار المزودات الحقيقي بطلب المالك، ولم تبدأ11.

## النتيجة

- مركز إشعارات دائم للتطبيقات الثلاثة، مع القراءة والتصفح وفتح الطلب المصرح به. الإسناد المنتهي أو الصلاحية المسحوبة لا يبقيان وصولًا عبر رسالة قديمة. لا بيانات محلية بديلة ولا نجاح Push وهمي.
- عامل outbox وإسقاط ذري ممنوع التكرار، وبث مستهدف ومجدولUTC بدفعات200 قابلة للاستئناف. إنشاء المسودة وجدولتها وإلغاؤها بمفتاح ثابت وتفويض عام حي. إلغاء قبل بدء الإسقاط فقط؛ sent تعني اكتمال إنشاء المركز.
- Expo Push adapter جاهز عبر FCM/APNs، مع enhanced security وticket/receipt وlease/retry/backoff وDeviceNotRegistered وإبطال generation دون مس نسخة أحدث. الرمز مربوط بجلسة المستخدم والتطبيق والبيئة والمشروع، ولا يظهر في DTO أوlogs. نجاحreceipt يعني تسليم المزود إلىFCM/APNs، وليس ظهورًا على جهاز. يمكن تكرارPush عند فقد إقرار خارجي؛ المركز ثابت مرة واحدة.
- تفضيل صوت لكل حساب وقناتان للنظام: تنبيه default وصامت. handler للـforeground وفتح الإشعار عند العودة/التشغيل، مع التحقق من الحساب والتصريح. لا ميكروفون أو صوت خلفي دائم، ولا ضمان صوت أو force-stop. تشغيلGo57 باقٍ، وPush الأصلي محروس بجهاز ونسخة ومشروع مهيأ؛ المركز متاح فيGo/web.
- صيانة العميل في الخادم والواجهة: catalog/preview/submit ترفض503 معRetry-After، ويُسلسل بدء الطلب مع تبديل الصيانة. الجاري وتفاعلاته والهوية والملفات والمركز والدعم والخصوصية والحذف خارج الحجب؛ الإدارة والموصل مستمران. خدمات الدعم والحذف الكاملة في11، ولم يُدّع إنجازها هنا.
- App Version API يختار البيئة من الخادم، ويقارن أرقام build لكل تطبيق ومنصة. الحد الأدنى إجباري والأحدث اختياري، مع رابط متجر صحيح وإقرار الموظف بتوفرbinary قبل حفظه. هذا إقرار بشري، وليس فحص متجر شبكيًا. build0 للويب/Go لا يمثل نسخة متجر ولا يفرض عليها بوابةbinary أخرى.
- staging/production وملفاتeas فعلية محروسة بmetadata عامة من backend فقط، ومعرّفات حزم يحددها المالك دون اختلاق. fingerprint وcheck/fetch مرة بعدroot دونreload أو تكرار كلforeground؛ التحديث المتوافق يستخدم فيcold start لاحق. لا نشر أوEAS build/update/submit خارجي.

## الإعدادات والحدود

سُجلت الأسماء اللازمة في `backend/.env` مع حفظ القيم الموجودة و600/gitignore: PUSH_PROVIDER وEXPO_ACCESS_TOKEN ومعرّفات مشاريعExpo الثلاثة وPUSH_TIMEOUT_MS، وAPI_URL وANDROID_PACKAGE وIOS_BUNDLE_IDENTIFIER لكل تطبيق. **EXPO_ACCESS_TOKEN هو سر الخادم؛ المعرّفات وبيانات البناء عامة.** [جدول الأسماء](../ENVIRONMENT.md). يبقى PUSH_PROVIDER=UNCONFIGURED الآن؛ لا قيم حقيقية مخترعة.

FCMv1 service-account وAPNs key/Key ID/Team ID فيEAS Credentials لكل تطبيق، وملفAndroid العام عبرمتغيرملفEAS GOOGLE_SERVICES_JSON؛ لا حاجة لنسخ مفاتيحFCM/APNs الخاصة إلىHTTP أوfrontend. prepare-native-config يرفض بيئة مصدر لا تطابق هدف البناء، ويكتب allowlist العامة دون أي سر. تهيئة API عام للهاتف وهوية حزم متاحة ورابط متجر وفحص أرشيفEAS تبقى قبل بناء فعلي.

لم تُختبر OTP/R2/Routing/Expo/FCM/APNs الحقيقية، ولا foreground/background/closed أورفضالإذن/الصوت/تبديلالرمز وSecureStore علىAndroid/iOS فعليين، ولا تنزيلB فيbinaryA وتشغيلB لاحقًا أو رفضruntimeC علىA. تلك مصفوفة معلقة صراحة بعد إضافة إعدادات المالك وطلب الفحص المجمع، كما فيRELEASES. لا تعد حزمHermes أوGo/manifests/HMR أو لقطاتChromium دليل جهاز. قرار المنطقة الزمنيةD15 باقٍ؛ الجدولة والوقتUTC.
