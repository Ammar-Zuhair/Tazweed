# أدلة المرحلة06

الصور لواجهات Expo نفسها المصدرة للويب. رحلة البيانات تعمل مع API وPostgreSQL حقيقيين في قاعدة مؤقتة، بحساب تشغيل SQL محدود. OTP يُلتقط داخل process الاختبار، وR2 وسيط ذاكرة لا يرسل إلى Cloudflare. صورة المنتج البرتقالية صورة اختبار صريحة؛ مرت عبر منتقي ملفات الويب وPUT والتحقق وإعادة الترميز والمصغرة، وليست صورة منتج أضيفت لقاعدة المراجعة.

[نتائج الجولات ووقتها](ui-checks.json)، [قبول الخادم وحراس SQL](acceptance.txt)، [الفحص العام وبصمات المصدر](../phase-06-checks.json)، [فحص الأنفاق والحزم](../phase-06-tunnels.json)، و[تقرير المرحلة](../phase-06.md).

## رحلة البيانات

| اللقطة | ما تثبته مع اختبارات API |
|---|---|
| [نموذج المنتج](admin-product-light-390.png) | دخول فعلي عبر API مع OTP اختبار معزول، قسم وخصائص وقيم، رفع صورة متحقق منها، رفض المنتج دون القيمة المطلوبة ثم حفظه. |
| [رصيد27](admin-stock27-light-390.png) | إنشاء حبة وكرتون12، ثم استلام/تسوية كرتونين و3حبات؛ رصيد فعلي27 ومحجوز0. لا إجمالي محلي بدل الخادم. |
| [منتج بفلتر اللزوجة](customer-filter-light-390.png) | اختيار المحافظة والزيوت و20W50 والبحث بالـSKU، وصورة مصغرة من محول التخزين، وعدم عرض المقاس في الزيوت. |
| [أدوات الكمية](customer-quantity-light-390.png) | عرض الوحدات والأسعار والتوافر من الخادم، وكمية كمسودة فقط؛ لا إرسال طلب أو حجز محلي. |
| [انقطاع API](customer-offline-light-390.png) | خطأ صريح واختفاء المنتج السابق دون استبداله بمنتجات fixtures. |

لقطات ScrollView تمثل موضع المراجعة الظاهر، وليست ملفًا يضم كل المحتوى القابل للتمرير. تحققت الرحلة برمجيًا من حفظ السجلات والقيم في PostgreSQL، والفلاتر والبحث، والرفض عند نقص الخاصية، وإعادة القراءة من الخادم.
