# المرحلة07 — الخرائط والتوصيل والعروض والسلة

نُفذ نطاق07 فقط بعد قراءة الذاكرة وتقرير06 وخطة07 ومراجعها: MASTER_PROMPT والمتطلبات وقرارات المالك وسجل القرارات والمشكلات، والمعمارية وقواعد العمل وAPI والقبول، مع مراجعة المخطط وشاشات العميل والإدارة. لا عائق في06 يمنع الأجزاء المستقلة؛ إعداد المزودات والمواقع الحقيقية بقي مؤجلًا وفق طلب المالك. لم تبدأ08.

## النتيجة

العميل يدير عناوينه المحفوظة في PostgreSQL، ويحدد الدبوس أو يدخل الإحداثيات أو يطلب الموقع عند الاستخدام. تعرض الخريطة MapLibre وإسناد OpenFreeMap/OpenMapTiles/OSM. أضيفت إدارة العروض الفعلية، ومعاينة سلة من الخادم تحسب أسعار فرع المحافظة والتوصيل وعرضًا واحدًا بأكبر توفير. لا حقائق سعرية أو نجاح حجز محلي.

**المعاينة لا تنشئ طلبًا أو عرضًا أو حجزًا أو outbox أو سجل تدقيق.** تعيد `previewOnly=true` و`reservationCreated=false` و`executionBranchId=null` و`reviewStage=awaiting_branch`. فرع الكتالوج تقديري هنا؛ المدير سيختار فرع التنفيذ عند إصدار العرض على طلب مرسل في08. لا nearest branch ولا تقسيم أو تجميع مخزون.

## الفحوص

نجح **77 اختبارًا للخادم والنقل و73 اختبارًا لحراس SQL على PostgreSQL الفعلي؛ المجموع150 دون فشل**. شملت المجموعة17اختبارًا جديدًا للمعاينة والعروض والطريق، إلى جانب58 للخادم السابق واختباري النقل. فُحصت الملكية وRBAC والعقود وغياب الكتابات والتزامن، و2.8كم وأقل من1كم، والتغطية وحد الطريق، وNoRoute والمهلة وsnap والرد المعيب وredirect وحد الحجم، وتوفير عرض متعدد SKU والتعادل والجملة وإعادة التسعير وتجاوز bigint.

نجحت فحوص الأنواع للتطبيقات الثلاثة والخادم، وبناء الخادم، وتصديرات الويب الثلاثة وحزم Hermes للمنصتين لكل تطبيق (6حزم). نجح `expo install --check` للعميل، ومطابقة OpenAPI، وفحص الأسرار في المصادر والحزم وملفات الخريطة المنشورة. لا مفاتيح backend أو قيمها المعروفة في هذه المخرجات. أنفاق Go الثلاثة اجتازت manifests وحزم Android/iOS وWebSocket؛ هذه ليست تجربة جهاز أو APK/IPA.


نجحت **7 جولات UI و27 لقطة**: رحلة مترابطة واحدة، ثم مصفوفة ثيمين×3مقاسات للشاشات الجديدة في العميل والإدارة. أثبتت حفظ عرض من الإدارة، دخولًا محققًا عبر API الاختبار، كميتي الحبة والكرتون، دبوس MapLibre ينتقل للنموذج، رفض إذن الموقع ثم إحداثيات Playwright، حفظ عنوان، floor_km وعرض توصيل،3←5، استبعاد الجملة، فشل الطريق، وتغيير المحافظة وإعادة التسعير. لا أخطاء pageerror أو طلبات مزود خارجي. SQL أثبت orders=quotes=holds=reserved=0 بعد الرحلة.

المتصفح يستعمل **API وقاعدة PostgreSQL مؤقتة حقيقيين**؛ لا DTO وهمية تحل محل حقائق الأعمال. OTP التقاط داخل process فقط، وRouting محول TestRouting وهندسة fixture معلّمة. محرك MapLibre وأصوله فعليان، لكن style الاختبار فارغ ومعزول، وإحداثيات المتصفح مصطنعة؛ لا إثبات لخرائط اليمن أو GPS هاتف أو طريق متجر فعلي. بيانات الاختبار حذفت مع قواعدها؛ لم تزرع حسابات أو مواقع تجريبية في قاعدة المراجعة.

## إعدادات المالك الجديدة

أُضيفت الأسماء إلى **`backend/.env`** فقط، مع حفظ القيم الموجودة وصلاحية600 وgitignore. `ROUTING_BASE_URL` كان محجوزًا؛ الأسماء الجديدة هي:

- `ROUTING_PROVIDER=UNCONFIGURED`؛ يغيّر إلى `osrm` بعد التجهيز.
- `ROUTING_API_KEY`؛ اختياري إذا كانت بوابة OSRM تحتاج Bearer.
- `ROUTING_PROFILE=driving`.
- `ROUTING_TIMEOUT_MS=5000`.
- `ROUTING_MAX_SNAP_M=200`.

يلزم لاحقًا ملء `ROUTING_BASE_URL` بعنوان الخدمة المملوكة، وإدخال مواقع الفروع الحقيقية والتغطية والتعرفة عبر الإدارة. لا حاجة لمفتاح OpenFreeMap العام. لا مفاتيح خدمات في frontend؛ فحص المصادر والحزم يشمل سر Routing الجديد. أسماء OTP وR2 السابقة محفوظة. [ENVIRONMENT](../ENVIRONMENT.md) و[ROUTING](../ROUTING.md) يوضحان الإعداد والاستضافة والتكلفة.

**لم تُختبر خدمات OTP/R2/Routing الحقيقية، بطلب المالك حتى يملأ مفاتيحها ويطلب اختبارها معًا.** لم تُشتر استضافة ولم يُستخدم demo للتسعير. مواقع المتجر الحقيقية وتجربة الهاتف وWebGL وSecureStore وGPS الفعلي وتغطية اليمن باقية؛ لا يخفيها نجاح اختبارات معزولة.
