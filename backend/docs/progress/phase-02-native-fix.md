# متابعة02 — إصلاح فيديو Android والعودة إلى Expo Go

أبلغ المالك عن Render Error عند إغلاق الافتتاحية على Android، وطلب development build، ثم أوقف هذا المسار وطلب إعادة التطبيقات إلى Expo Go. نُفذ طلبه الأحدث للتطبيقات الثلاثة مع إبقاء إصلاح الفيديو. التزام البداية `7e8f54374a295fa5e527bc5e312059fceec2b8ca`. لم تبدأ03 أو خدمات الأعمال.

## سبب خطأ الفيديو وإصلاحه

كان cleanup في `customer-app/integration/IntroScreen.tsx` يستدعي `player.pause()` بعد أن حرر hook `useVideoPlayer` المشغّل. شيفرة expo-video57.0.5 وexpo-modules-core المثبتة تؤكد أن SharedObject يحرر في cleanup داخلي سابق؛ وهذا يطابق موضع الخطأ الذي أرسله المالك. فحص الويب السابق لم يثبت ترتيب التحرير في Android.

أزيل استدعاء المشغّل من تنظيف الشاشة. يلغي التنظيف المؤقت والمستمعين ويعطل callbacks المتأخرة، ويظل hook مسؤولًا عن release. أضيف `integration/intro-lifecycle.ts` لإكمال الافتتاحية مرة واحدة عند التخطي أو النهاية أو المهلة أو الخطأ؛ ويحمي pause وقراءة status وplay من سباق التحرير. فشل الفيديو لا يمنع دخول التطبيق. بقيت الفيديوهات والمدة والصوت والتخطي وتقليل الحركة والخلفية وعدم إعادة الفيديو أثناء الملاحة. [مرجع Expo57 لدورة حياة المشغّل](https://docs.expo.dev/versions/v57.0.0/sdk/video/).

خمسة اختبارات ارتدادية تحاكي تحرير hook قبل تنظيف الشاشة، والأحداث المتأخرة، ورفض pause مع تعدد أسباب الإكمال، وقراءة مشغّل محرر، والتشغيل الطبيعي ودورة effects في التطوير. هذه محاكاة لحدود دورة الحياة، وليست تشغيل Java/Fabric على هاتف المالك. يلزم إعادة تجربة النسخة المصححة في Expo Go على هاتفه لتأكيد زوال الخطأ.

## الحالة النهائية للتشغيل

- التطبيقات الثلاثة على Expo57.0.31 / SDK57، و`npm start` يستهدف `expo start --tunnel --go` على8091/8092/8093.
- أزيلت حزمة expo-dev-client وplugin وprofile development وأوامر وأدوات APK غير المسلمة. عاد package.json والقفل وapp.config.ts وeas.json للتهيئة السابقة الخاصة بـGo.
- أوقفت خدمة العميل المعروفة وأعيد إنشاؤها بوضع Go؛ الإدارة والموصل أعيد استخدام خدمتيهما العاملتين في Go. سكربت التشغيل يعيد إنشاء وحدته إذا اختلف وضع runtime، ويحمي المنافذ المملوكة لخدمات أخرى.
- تعرض إعدادات العميل بيئة التشغيل الفعلية: Expo Go على الهاتف ومعاينة ويب في المتصفح.
- لم يكتمل APK قبل إيقاف المالك لمسار البناء، ولا يسلم APK أو يدّعى فحص جهاز. تأكد عدم بقاء Gradle أو سكربت البناء، وأزيل مشروع android المولد للمحاولة. بقيت caches الأدوات محلية مستبعدة من Git.
- لا يشغل Expo Go مكتبة أصلية غير مضمنة فيه بمجرد إضافتها إلى JavaScript. تعارض MapLibre/Go يبقى مسجلًا قبل ربط الخرائط07؛ لا مكتبة خرائط أو خدمات جديدة ضمن هذه المتابعة.
