# المرحلة04 — واجهات الموصل ومراجعة التطبيقات الثلاثة

نفذت04 فقط بعد طلب المالك ومراجعته03، من المصدر `abb8748`. قرئت الذاكرة وتقرير03 وMASTER_PROMPT وOWNER_DECISIONS_PHASE00 وISSUES وREQUIREMENTS وDECISIONS، وقوائم شاشات التطبيقات الثلاثة وBUSINESS_RULES وACCEPTANCE، مع عقد API ودليل الهوية والمراجع ذات الصلة. لا عائق سابق يمنع الواجهات المحلية؛ حسم MapLibre/Expo Go والبيانات التشغيلية والسياسة باقٍ لمواعيده.

التسليم واجهات موصل قابلة للتشغيل ومراجعة اتساق [UI_REVIEW.md](../../../UI_REVIEW.md). لا خدمات أعمال أو DB/migrations أو تنفيذ05. التطبيقات الثلاثة باقية على SDK57 وExpo Go. لم يفترض اعتماد المالك لهذه المراجعة أو موافقته على بدء الخدمات.

## القواعد الفارقة

- بيانات المهام هي نسخ إسناد، لا نسخ طلب قابل للتحرير. يرفض النموذج المحلي هوية موصل أخرى أو assignment قديمًا أو expectedVersion قديمة. إعادة الإسناد وانتهاؤه لا تعيدان بيانات خاصة عند إعادة محاولة قديمة. هذه محاكاة لحراس العقد، وليست أمان خادم أو منع وصول إلى بيانات fixture داخل حزمة JavaScript.
- عند إرسال العملية تحفظ بياناتها ومفتاحها في الذاكرة. لا تنتقل حالة الطلب حتى إقرار المحاكاة أو قراءة حالة محدثة منها. الانقطاع لا يعني النجاح أو الفشل النهائي؛ عند فقد الإقرار بعد تنفيذ محلي يعيد المفتاح نفسه النتيجة دون تحصيل أو عمولة أو وقت تسليم جديد. لا worker أو queue خلفية حقيقية، ولا ضمان بقاء العمليات بعد إغلاق JavaScript.
- قبل تسليم النقد: تحصيل مطابق أو استثناء مسجل يطابق المبلغ الفعلي الحالي. استثناء صفر قديم لا يغطي تحصيلًا ناقصًا لاحقًا. المرجع مستخدم مرة، ولا يستبدل تحصيل قديم. التصحيح/التوريد الحقيقي لدى الإدارة في مراحله. طلب التحويل لا يعرض إيصال العميل ولا يسجل له نقدًا.
- مثال500−خصم100 عند20%=100عمولة، ورسوم العميل400. عند تحصيل24400 تبقى عهدة المتجر24400 دون طرح100. تثبت النسبة عند الإسناد؛ حساب770000012 الحالي15% في fixtures الإدارة، وبعض إسناداته القديمة هنا20% صراحة. العكس يعيد المتاح غير المسدد، دون زيادة عمولة اليوم.
- cache في الذاكرة فقط، صالح5دقائق كتحديد تقني للمعاينة، ومحصور بالمسند. عند انتهاء النسخة أو صلاحية الإسناد المعروفة تزال تفاصيل العميل والبلاغات والإشعارات التابعة. الخروج يمسح النسخة والمسودات والعمليات، مع تنبيه أن الخروج لا يلغي عملية سبق إقرارها. لا يستطيع جهاز منقطع معرفة سحب إسناد بعيد قبل التحديث/انتهاء النسخة. لا سياسة احتفاظ قانونية مختلقة.

## الملفات والتنظيم

`courier-app/src/domain/{types,courier-model}.ts` للعقود والقواعد، و`fixtures/courier-fixtures.ts` لبيانات وهمية معلّمة. `data/courier-repository.ts` يفصل القراءة والإرسال والمحاكاة، و`courier-provider.tsx` يدير الجلسة والنسخة والإلغاء والعمليات. `courier/components.tsx` للمكونات والحوار، و`screens.tsx` للشاشات ومساراتها الصغيرة في `src/app`. اختبارات مستقلة في `tests/courier.test.ts`، مع أساس01 السابق.

إضافات exact: `expo-audio57.0.5` و`expo-image-picker57.0.20` و`expo-clipboard57.0.2` مع lockfile. مطابقة لمصفوفة SDK57 ومشمولة في Go؛ لا dev-client. نغمة `assets/task-tone.wav` قصيرة مولدة محليًا لهذه المعاينة؛ لم تعدل أصول الهوية/الفيديو/الخطوط الأصلية. plugins تعطل الكاميرا والميكروفون والخلفية، والموصل لا يطلب إذن موقع. introspect يفحص إعدادًا مولدًا فقط ولا يبني APK أو يغير تطبيق Go المثبت. [مرجع Audio57 الرسمي](https://docs.expo.dev/versions/v57.0.0/sdk/audio/) و[ImagePicker57](https://docs.expo.dev/versions/v57.0.0/sdk/imagepicker/).

أضيفت أدوات evidence وtest/verify-courier-phase04، وأصبحت بادئة الأنفاق/تراجع الافتتاحية الافتراضية04. أضيف خيار بادئة04 لمراجعة العميل/الإدارة مع حفظ أدلتهما التاريخية. مصدر العميل والإدارة وbackend/src والمخطط بلا تغيير عن `abb8748`؛ لم تنفذ مراجعة الواجهات خدمة مشتركة جديدة.
