# تحسين واجهات العميل بعد04

تنفيذ خطة المالك المعتمدة لتحسين العميل فقط بعد مراجعة04، دون بدء05. قرئ `remember.md` وتقرير04 ومراجعة الواجهات والشيفرة الحالية. تطبيقَا الإدارة والموصل باقِيان على مصدرهما السابق؛ تغييرات backend هنا أدوات فحص ووثائق فقط. التشغيل Expo Go / SDK57، والبيانات محلية معلّمة.

## ما تغير

- الرئيسية: رأس مختصر ومحافظة، ثم «عروض لك» في `FlatList` أفقي يدعم RTL والسحب اليدوي، مع جزء من العرض التالي وثلاثة مؤشرات قابلة للضغط. لكل عرض وجهة: العروض والزيوت والبطاريات. لا تحريك تلقائي.
- الأقسام الستة تحت العروض؛ النقر يفتح كتالوج القسم. البحث بالاسم/الرمز والعلامة مع اللزوجة للزيوت والسعة للبطاريات وبقية الخصائص. الانتقال إلى قسم آخر من الكتالوج أو الرئيسية يمسح الفلاتر السابقة، واختيار شرائح القسم يحدّث المسار كي لا يبقى قسم سابق عند العودة.
- «الأكثر طلبًا اليوم» تحت الأقسام: قراءة محلية مستقلة حسب المحافظة واليوم، بحد6 منتجات وترتيب طلبات تجريبي مستقل عن `featured`. يظهر التاريخ وUTC ووسم «ليس إحصاء مبيعات فعليًا». لا مصدر مبيعات حقيقي قبل الربط؛ UTC لا يحسم D15.
- دوائر وحلقات برتقالية خلف جميع صفحات العميل المشتركة، بدرجات مناسبة للفاتح والمظلم؛ لا تعترض اللمس ولا تشارك في شجرة الإتاحة. لا أصول أو مكتبات جديدة.
- عمود للمنتجات تحت390، عمودان من390، وثلاثة من768؛ نقاط اللمس للأدوات44px على الأقل. الصورة والاسم يفتحان التفاصيل؛ أدوات الوحدة والطلب مستقلة عنهما.
- بطاقة المنتج تعرض سعر الحبة/الكرتون والتحويل الصحيح، وتتيح «طلب» مباشرة. عند الإضافة تظهر أدوات ناقص/حقل قابل للكتابة/زائد، وملخص جميع وحدات المنتج في السلة. الحبة والكرتون بندان مستقلان.
- أمر `cart-set` يضبط كمية مطلقة. الحقل يقبل الأرقام العربية والإنجليزية والفارسية من1 إلى999؛ الفراغ أثناء التحرير لا يغير السلة، والخطأ لا يحفظ قيمة. الناقص من1 إلى0 يحذف بند الوحدة فقط.
- التفاصيل تبدأ بكمية الوحدة الموجودة أو1، وتعرض «تحديث الكمية» للبند الموجود. حفظ3←5 يترك5، دون جمعها إلى8. تتزامن البطاقة والتفاصيل والسلة. المنتج/الوحدة غير المتاحين يمنعان الإضافة والزيادة، مع السماح بتقليل أو حذف بند احتفظت به السلة عند تغيير المحافظة.
- الفيديو: لا تفسّر حالة بدء `null/inactive/background` باعتبارها مغادرة بعد العرض. تنتظر أول `active` قبل تشغيل مؤقت4750ms والتشغيل بعد جاهزية الفيديو وفحص تقليل الحركة. بعد العرض تنهيه الخلفية، وكذلك التخطي/النهاية/الفشل؛ لا إعادة أثناء التنقل. بقي تحرير المشغل مسؤولية `useVideoPlayer` بلا استدعاءات عليه في cleanup، وبقيت بايتات الفيديو الأصلي كما هي. [مرجع Expo Video57](https://docs.expo.dev/versions/v57.0.0/sdk/video/).

«طلب» من البطاقة يضيف إلى السلة؛ إرسال الطلب النهائي يبقى من checkout والمراجعة الحالية. لا حفظ دائم جديد للسلة أو خدمات/سياسات مالية أو مزودات جديدة.

| مراجعة الواجهة |6 جولات: الفاتح والمظلم عند360/390/1024، تشمل العودة للقسم الصحيح والطلب المباشر والتزامن|

أوامر إعادة الفحص من جذر المستودع:

```bash
npm --prefix customer-app run typecheck
npm --prefix customer-app test
npm --prefix customer-app run export:web
npm --prefix customer-app run export:native
node backend/scripts/test-customer-refresh.mjs
TAZWEED_CUSTOMER_EVIDENCE_PREFIX=customer-ui-refresh-regression TAZWEED_UI_RUNS=0 node backend/scripts/test-customer-phase02.mjs
PHASE01_EVIDENCE_PREFIX=customer-ui-refresh node backend/scripts/test-previews.mjs
TAZWEED_EVIDENCE_PREFIX=customer-ui-refresh node backend/scripts/verify-expo-tunnels.mjs
node backend/scripts/verify-customer-refresh.mjs
```

التحقق المتصفحي يحاكي السحب الأفقي بأحداث مؤشر/عجلة، ولا يثبت حركة اللمس أو قارئ الشاشة على جهاز. الاختبارات المنطقية تغطي انتظار الحالة النشطة وسباق التحرير، والمتصفح يحاكي بداية مخفية5ثوانٍ تتبعها حالة نشطة ثم خلفية. عند تشغيل الجولة الطويلة عبرsystemd مررت PLAYWRIGHT_BROWSERS_PATH لموضع المتصفح المثبت. نجاح export أو manifest أو الحزمة لا يثبت تشغيل هاتف أو سماع صوت. على المالك تجربة فتح رابط العميل لأول مرة من Expo Go، والثيمين، والتخطي والخلفية، وإدخال الكمية بلوحة مفاتيح الهاتف.

## التشغيل

| التطبيق | Expo Go | الوحدة | المنفذ/مسار الصحة |
|---|---|---|---|
| العميل | `exp://sfs3nam-anonymous-8091.exp.direct` | `tazweed-customer-expo-8091` |8091 `/status`|
| الإدارة | `exp://utjz9oi-anonymous-8092.exp.direct` | `tazweed-admin-expo-8092` |8092 `/status`|
| الموصل | `exp://vsfhyqu-anonymous-8093.exp.direct` | `tazweed-courier-expo-8093` |8093 `/status`|

الأنفاق فُحصت مجددًا، مع manifests وحزم Android/iOS وWebSocket العامة، والخدمات systemd تبقى بعد الجلسة. الروابط مؤقتة وقد تتغير بعد إعادة التشغيل؛ وقت الفحص وQR في دليل الأنفاق. معاينة العميل `/` على [الرابط الموجّه](https://tazweed--8081.dev.remote-ammar.duckdns.org/) عبر `tazweed-customer-preview-8081`؛ قد تتطلب تسجيل دخول remote. HTTP302 يثبت ingress فقط، والفحص الوظيفي للمتصفح كان محليًا.

التوقف بعد تحسينات العميل. الخدمات الحقيقية والهاتف الأصلي و05+ باقية ضمن مراحلها؛ هذه المراجعة ليست اعتمادًا للواجهات من المالك.
